# Identity Package UDP Listener

## Ambient Physical AI

**Distributed Cognitive Ecosystem Powered by StackFlow**

---

## Purpose

This component implements the first integration milestone between the Identity Layer and the Cognitive Runtime Node.

Its purpose is to validate reliable transport of an Identity Package generated by the Identity Node (M5Dial) to the Cognitive Runtime Node (AX630C).

This milestone focuses exclusively on communication validation.

No reasoning, context injection, LLM inference, StackFlow orchestration, MQTT messaging or ambient actions are performed at this stage.

---

## Architecture

```text
NFC Tag
   ↓
Identity Node V1
(M5Dial)
   ↓
Identity Package
(JSON)
   ↓ UDP 4444
AX630C
Cognitive Runtime Node
   ↓
identity_udp_listener.py
   ↓
Identity Package received
```

### Components

| Component                | Function               |
| ------------------------ | ---------------------- |
| M5Dial                   | Identity Node          |
| WS1850S                  | NFC Reader             |
| AX630C + LLM Mate        | Cognitive Runtime Node |
| UDP Port 4444            | Transport Layer        |
| identity_udp_listener.py | Validation Listener    |

## Validation Procedure

### Step 1

Boot the AX630C listener.

### Step 2

Boot the Identity Node V1 firmware.

### Step 3

Ensure Wi-Fi connectivity between:

```text
M5Dial
↓
AX630C
```

### Step 4

Present a registered NFC tag.

### Step 5

Verify that the Identity Package is generated by the Identity Node.

### Step 6

Verify that the AX630C receives the UDP packet.

## Troubleshooting

### Listener not receiving packets

Verify:

```bash
ifconfig eth0
```

Confirm AX630C network connectivity.

---

### Invalid JSON

Verify that the Identity Node firmware is generating a valid Identity Package.

---

### Wi-Fi disconnected

Verify Identity Node Wi-Fi configuration.

---

### Wrong IP Address

Verify the configured AX630C IP address in the Identity Node firmware.

Example:

```cpp
#define AX630C_IP "192.168.77.15"
#define AX630C_UDP_PORT 4444
```
