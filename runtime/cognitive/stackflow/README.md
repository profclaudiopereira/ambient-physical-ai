# StackFlow Cognitive Runtime

## Ambient Physical AI

**Distributed Cognitive Ecosystem Powered by StackFlow**

---

This directory contains the experimental laboratories developed for the Ambient Physical AI Cognitive Runtime.

The laboratories are organized as incremental engineering milestones, preserving validation evidence, reproducibility and architectural decisions throughout the project.

---

## Purpose

This component implements the first integration milestone between the Identity Layer and the Cognitive Runtime Node.

Its purpose is to validate reliable transport of an Identity Package generated by the Identity Node (M5Dial) to the Cognitive Runtime Node (AX630C).

This milestone focuses exclusively on communication validation.

No reasoning, context injection, LLM inference, StackFlow orchestration, MQTT messaging or ambient actions are performed at this stage.

---

## Architecture

```text
NFC Tag
   ↓
Identity Node V1
(M5Dial)
   ↓
Identity Package
(JSON)
   ↓ UDP 4444
AX630C
Cognitive Runtime Node
   ↓
identity_udp_listener.py
   ↓
Identity Package received
```

### Components

| Component                | Function               |
| ------------------------ | ---------------------- |
| M5Dial                   | Identity Node          |
| WS1850S                  | NFC Reader             |
| AX630C + LLM Mate        | Cognitive Runtime Node |
| UDP Port 4444            | Transport Layer        |
| identity_udp_listener.py | Validation Listener    |

The next milestone is to replace fixed responses with real Ambient Physical AI runtime services, including Identity, Presence, Context and future Cognitive Runtime capabilities.

## Context Package V1 Validation

This laboratory validated the first semantic representation produced by the Cognitive Runtime.

The Context Builder no longer generates only a human-readable message.

Its primary responsibility is now to transform validated physical events into a semantic Context Package following the 5W Context Model.

Validated execution flow:

```text
Identity Node (M5Dial)
        │
        ▼
Identity Package
        │
        ▼
UDP Transport
        │
        ▼
AX630C Cognitive Runtime
        │
        ▼
Context Builder
        │
        ▼
5W Context Package
```

Validated Context Package structure:

```text
Who
Where
When
What
Why
```

Current implementation:

- WHO is populated from the Identity Package.
- WHERE is populated from the environment context.
- WHEN is generated by the Cognitive Runtime.
- WHAT represents the validated runtime activity.
- WHY is reserved for future semantic reasoning.

The Context Package becomes the primary semantic object of the Ambient Physical AI Cognitive Runtime.

Human-readable messages remain available only for debugging and validation compatibility.

StackChan delivery remains suspended pending the dedicated MCP integration laboratory.
