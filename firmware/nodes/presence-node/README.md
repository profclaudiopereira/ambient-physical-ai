# Overview

The Presence Node is the first operational firmware of the Ambient Physical AI ecosystem.

Its purpose is to validate:

* ESP-IDF development environment;
* build system;
* flashing process;
* runtime execution;
* repository organization;
* initial node architecture.

This firmware currently runs on:

* M5Stack CoreS3 Lite
* ESP32-S3
* ESP-IDF 5.4.2
