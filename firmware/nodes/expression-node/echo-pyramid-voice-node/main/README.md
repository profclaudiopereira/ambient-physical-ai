# Overview

The **Echo Pyramid Voice Node** is the Expression Layer node responsible
for transforming semantic events generated by the Cognitive Runtime into
physical interaction.

Current capabilities:

-   RGB semantic feedback
-   Local LCD status interface (AtomS3R)
-   Wi-Fi communication
-   UDP semantic event reception
-   Personalized welcome messages
-   Engineering baseline for future wake-word and voice-command support

This node intentionally performs **expression**, not cognition. All
reasoning remains in the AX630C Cognitive Runtime.

# Building

## Requirements

-   ESP-IDF 5.4.2
-   Git
-   Python (installed by ESP-IDF)
-   USB cable

Clone the repository:

``` bash
git clone https://github.com/profclaudiopereira/ambient-physical-ai.git
cd ambient-physical-ai
```

Enter the firmware:

``` bash
cd firmware/nodes/expression-node/echo-pyramid-voice-node
```

Set the ESP-IDF environment.

Windows:

``` bash
export.bat
```

Linux/macOS:

``` bash
source export.sh
```

Select the serial port:

``` bash
idf.py set-target esp32s3
idf.py -p COM5 build
```

Flash:

``` bash
idf.py -p COM5 flash
```

Monitor:

``` bash
idf.py -p COM5 monitor
```

3.  Building with `idf.py build`.
4.  Flashing with `idf.py flash`.
5.  Sending UDP semantic events.

No proprietary tools are required.
