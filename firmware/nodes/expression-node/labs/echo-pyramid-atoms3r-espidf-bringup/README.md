# Echo Pyramid + AtomS3R ESP-IDF Bring-up

## Ambient Physical AI

### Expression Layer — E01 Boot Serial Baseline

---

# Objective

This laboratory marks the first ESP-IDF firmware developed for the Echo Pyramid + AtomS3R platform.

Unlike the previous Arduino laboratory, this project represents the beginning of the official Expression Layer implementation used by Ambient Physical AI.

The objective is intentionally minimal:

* validate the ESP-IDF development environment;
* validate firmware build;
* validate firmware flashing;
* validate serial communication;
* establish the first reproducible ESP-IDF baseline.

No hardware peripherals are validated in this milestone.

---

# Hardware

| Component    | Role                               |
| ------------ | ---------------------------------- |
| AtomS3R      | ESP32-S3 host controller           |
| Echo Pyramid | Expression Layer hardware platform |

---

# Scope

This milestone validates only:

* ESP-IDF project structure
* ESP32-S3 target
* Successful compilation
* Successful flashing
* Serial monitor
* Runtime heartbeat

---

# Out of Scope

The following features are intentionally postponed to future milestones:

* RGB control
* Touch interface
* Audio codec
* Microphone
* Speaker
* Wi-Fi connectivity
* UDP communication
* Semantic Event reception
* Cognitive Runtime integration

Keeping the first milestone intentionally small improves reproducibility and simplifies debugging.

# Engineering Purpose

This laboratory establishes the official ESP-IDF baseline from which all future Expression Layer development will evolve.

The objective is to confirm that:

* the development environment is correctly configured;
* the AtomS3R boots correctly under ESP-IDF;
* serial logging is operational;
* future peripherals can be added incrementally.

---

# Architectural Note

The Expression Layer does not perform semantic reasoning.

It consumes Semantic Events generated by the Cognitive Runtime.

It shall not consume:

* Identity Packages
* 5W Context Packages
* Current Runtime Context
* Decision Engine internal state

These remain private cognitive representations inside the Cognitive Runtime.
