# StickC Plus 2 RGB Node

## Ambient Physical AI

### Expression Layer

------------------------------------------------------------------------

# Overview

The **StickC Plus 2 RGB Node** is a production Expression Layer device
of the Ambient Physical AI ecosystem.

Its responsibility is intentionally limited to translating normalized
Semantic Events generated by the Cognitive Runtime into synchronized
visual feedback using:

-   External WS2812 RGB LED strip
-   Integrated M5StickC Plus 2 display

The node does **not** perform reasoning, context generation,
authorization, or AI inference.

``` text
Semantic Event
        │
        ▼
Expression Processor
        │
        ▼
RGB Effects
        │
        ▼
RGB Controller
        │
 ┌──────┴────────┐
 ▼               ▼
Display      WS2812 LEDs
```

------------------------------------------------------------------------

# Mission

Provide deterministic visual feedback for semantic events while
remaining fully decoupled from cognitive reasoning.

# Semantic Event Contract

The node listens for normalized UDP semantic events.

Example:

``` json
{
  "type": "semantic_event",
  "event": "identity_authenticated",
  "target": "rgb_strip"
}
```

Default UDP port:

``` text
5555
```

# Engineering Decisions

-   Hardware-specific logic is isolated inside `rgb_controller.cpp`.
-   Semantic processing remains hardware independent.
-   Display and LED strip are always updated together.
-   UDP delivery contract is shared with other RGB Expression Nodes.
-   The Cognitive Runtime preserves the historical `RGBStripNotifier`
    adapter while supporting multiple RGB nodes.
