# STACKCHAN_MCP_DISCOVERY_001

## Ambient Physical AI

**Distributed Cognitive Ecosystem Powered by StackFlow**

---

# Objective

Investigate whether the AX630C Cognitive Runtime can safely integrate with the StackChan/XiaoZhi ecosystem through the Model Context Protocol (MCP).

The primary objective of this laboratory was **not** to control the StackChan, but to determine whether contextual information generated by the Ambient Physical AI runtime could be exposed to StackChan through the MCP architecture.

---

# Background

The previous StackChan integration laboratory focused on delivering human-readable messages generated by the AX630C Cognitive Runtime.

During that investigation, an important architectural observation was made.

The StackChan firmware exposed an MCP endpoint similar to:

```text
wss://api.xiaozhi.me/mcp/?token=<REDACTED>
```

This observation suggested that StackChan was not receiving arbitrary messages directly from external applications.

Instead, it appeared to communicate through an MCP broker.

As a consequence, the previous notification laboratory was intentionally suspended until the MCP protocol could be understood.

---

# Initial Hypothesis

The original hypothesis assumed a direct communication model:

```text
AX630C
↓
StackChan
```

During this laboratory, the hypothesis evolved into:

```text
AX630C
↓
MCP Tool Provider
↓
XiaoZhi MCP Broker
↓
LLM
↓
StackChan
```

The objective of this laboratory was to validate or reject this architectural hypothesis.

# Security

The MCP endpoint contains an authentication token.

During this laboratory:

* no token was committed to Git;
* no documentation contains real token values;
* all logs use:

```text
wss://api.xiaozhi.me/mcp/?token=<REDACTED>
```

The endpoint is configured only through environment variables.

Determine whether the broker requests available tools.

```text

```

PASS

PASS

PASS

# Architectural Conclusions

The AX630C has been experimentally validated as an MCP Tool Provider for the StackChan/XiaoZhi ecosystem.

The laboratory demonstrated that semantic information can be supplied by the Ambient Physical AI Cognitive Runtime through MCP tools without requiring any modification to the StackChan firmware.

This significantly changes the architectural integration strategy originally envisioned for the project.

Instead of transmitting arbitrary messages directly to StackChan, the Cognitive Runtime exposes semantic services that may be invoked by the LLM through the MCP broker.
