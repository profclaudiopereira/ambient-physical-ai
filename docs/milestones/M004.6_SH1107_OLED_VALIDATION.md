# M004.6 — SH1107 OLED Validation

## Objective

Validate the M5Stack Unit OLED 1.3" (SH1107 controller) connected through PaHub on the Ambient Runtime Node running ESP-IDF.

## Hardware

* M5Stack Unit PoE-P4
* M5Stack PaHub
* M5Stack Unit OLED 1.3"
* SH1107 Controller
* I2C Address: 0x3C

## Validation Steps

### Step 1 — I2C Detection

The OLED was successfully detected on the I2C bus.

Detected devices:

* 0x70 (PaHub)
* 0x3C (SH1107 OLED)

### Step 2 — Driver Bring-up

A dedicated ESP-IDF component (`oled_sh1107`) was created.

Capabilities implemented:

* Initialization sequence
* Command transmission
* Data transmission
* Page and column addressing
* Display clear operation

### Step 3 — Rendering Validation

Several low-level rendering experiments were performed:

* Full screen patterns
* Vertical bars
* Offset investigations
* Page mapping validation
* Character rendering

These experiments confirmed correct controller initialization and memory addressing.

### Step 4 — Text Rendering Validation

Custom glyph rendering was implemented.

Test strings displayed successfully:

* OK
* AI
* RUN
* TES

Result:

* Text visible
* Correct orientation
* Correct page mapping
* Correct column mapping
* Stable rendering

## Conclusion

The SH1107 display is fully operational under ESP-IDF.

The Ambient Runtime Node now supports:

* Environmental sensing (ENV-IV)
* OLED visualization (SH1107)
* PaHub-based I2C expansion

This milestone establishes the foundation for runtime dashboards and contextual ambient feedback.
