# Objective

Validate the complete semantic processing pipeline for the RGB Strip Expression Node.

This milestone demonstrates that the node is capable of:

- connecting to the project Wi-Fi network;
- receiving semantic events through UDP;
- validating JSON payloads;
- filtering messages by target;
- processing semantic events;
- executing physical RGB expressions.
