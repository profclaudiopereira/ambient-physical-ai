# Context-Aware Cognitive Lab

## Official Demonstration Scenario

Ambient Physical AI is demonstrated through a contextual laboratory environment inspired by:

- Mark Weiser;
- Ubiquitous Computing;
- Context-Aware Computing;
- Ambient Intelligence.

The objective is to demonstrate how a distributed cognitive ecosystem can perceive, identify, understand and adapt to human presence.

---

# Scenario

The demonstration takes place inside a technology laboratory or innovation space.

The environment contains multiple specialized nodes connected through the Ambient Physical AI architecture.

A participant enters the laboratory and interacts naturally with the environment.

---

# Hardware Participation

## Presence

```text
LD2410C Radar Presence Node
```

Detects human presence and initiates the interaction flow.

## Identity

```text
M5Dial + WS1850S NFC
```

Authenticates the participant and activates the corresponding contextual profile.

## Cognition

```text
AX630C + LLM Mate
```

Maintains the Current Runtime Context, coordinates semantic processing and publishes runtime state and semantic events.

## Ambient Runtime

```text
M5Stack Tab5
```

Consumes contextual information, presents local and personalized information, and coordinates environmental adaptation.

## Expression Layer

```text
StackChan
Echo Pyramid + AtomS3R
RGB Expression Nodes
Wearable Haptic Node
Cognitive Runtime Console
```

Expresses the active cognitive state through voice, visual, embodied and haptic feedback.

---

# Demonstration Example

A participant enters the laboratory.

The LD2410C Presence Node detects human presence.

The participant authenticates through an NFC credential using the M5Dial and WS1850S reader.

The AX630C Cognitive Runtime creates and activates the participant context.

The M5Stack Tab5 updates the Ambient Runtime interface and personalized information.

StackChan becomes available as an embodied research assistant.

The Echo Pyramid delivers a personalized welcome and supports wake-word-driven context change requests.

RGB Expression Nodes and the Wearable Haptic Node reflect the current runtime state through synchronized visual and tactile feedback.

The Cognitive Runtime Console presents runtime state, identity, context and system observability information.

The environment becomes contextually aware of who arrived and adapts its behavior accordingly.

---

# Key Message

Ambient Physical AI is not a home automation system.

It is a context-aware cognitive environment capable of perceiving, identifying, interpreting and adapting to human presence through a distributed architecture of specialized runtime nodes.
